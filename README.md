# 🔄 What Does This Program Do?

The User-Friendly Edition focuses on two main conversions:

## 🟢 `.KTML` → `progress.sav`

If you have compatible KTML save data and need a normal Tears of the
Kingdom `progress.sav`, use:

**`.KTML → progress.sav`**

---

## 🔵 `progress.sav` → `.KTML`

If you have a Tears of the Kingdom `progress.sav` and need compatible
KTML save data, use:

**`progress.sav → .KTML`**

---

# ⚠️ Renaming a File Is NOT Conversion

This is important.

Changing:

    progress.sav

to:

    progress.ktml

does **NOT** actually convert the save.

The formats contain structured save information that has to be properly
read and converted.

That's what this application is designed to do.

# 🌐 Using a Converted Save With a Multiplayer Realm

If you're converting a save because you're working with a multiplayer
realm/server, be careful when replacing live save data.

## PAUSE THE REALM FIRST.

A server may be actively reading or writing save information while it
is running.

Replacing files at the wrong time can cause problems.

A safer workflow is:

1. Back up your save.
2. Pause the realm.
3. Download/export the save you need.
4. Make another copy.
5. Convert the COPY.
6. Upload/replace the appropriate converted save.
7. Confirm everything completed successfully.
8. Resume the realm.
9. Join the game.
10. Verify your save works.

# 🩺 Something Went Wrong?

Don't panic.

And more importantly:

## DON'T DELETE YOUR BACKUP.

Open:

**Diagnostics & Error Reports**

Explain what you were doing when the problem happened.

For example:

> I selected progress.sav, clicked Convert to .KTML, and received an
> error before the output file was created.

The more clearly you explain what happened, the easier it is to
investigate.

---

# 📋 Creating an Error Report

Inside **Diagnostics & Error Reports**, you can collect useful
information about the problem.

When reporting a bug, please tell us:

- You're using **User-Friendly Edition v2.6**
- You're using **TOTK v1.2.1**
- Which conversion you attempted
- `.KTML → progress.sav` or `progress.sav → .KTML`
- What you expected to happen
- What actually happened
- The exact error message
- Whether the error happens every time
- Steps that reproduce the problem
- Your diagnostic report, if available

A screenshot can also help.

---

# 🔐 Protect Your Private Information

Before posting a diagnostic report or screenshot publicly:

## CHECK IT FIRST.

Do not share:

- Passwords
- Authentication tokens
- API keys
- Private keys
- Login credentials
- Browser cookies
- Personal information
- Anything else you don't want publicly visible

The application can attempt to sanitize diagnostic information, but
automatic redaction should never replace checking the report yourself.
